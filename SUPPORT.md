# Support

HEZQEN Infrastructure Standard is an engineering-preview repository. Support is provided through public GitHub issues; no paid support or response-time guarantee is offered.

## Where to ask

- Usage and setup questions: [open an issue](https://github.com/LloydCoder/hezqen-infrastructure-standard/issues/new).
- Defects: use the [bug report form](https://github.com/LloydCoder/hezqen-infrastructure-standard/issues/new?template=bug_report.yml).
- Feature or standards proposals: use the [feature request form](https://github.com/LloydCoder/hezqen-infrastructure-standard/issues/new?template=feature_request.yml).
- Security vulnerabilities: do not use public issues. Follow [SECURITY.md](SECURITY.md).

## Include useful context

Include the repository commit or product version, OS and architecture, Python and Docker versions where relevant, exact command and sanitized output, expected and observed behavior, minimal reproduction steps, and checks already run.

## Support boundaries

The project does not guarantee compatibility with every model, GPU, operating system, container runtime, cloud provider, or third-party dependency. Product workspaces document tested configurations and known limitations. Do not share credentials, personal data, customer content, or private operational details in public tickets.
