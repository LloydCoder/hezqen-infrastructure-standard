# Benchmark Methodology Standard

Every published benchmark must be reproducible and include the source revision, hardware, software stack, workload, dataset characteristics, configuration, warm-up, run count, aggregation method, and environmental constraints.

Report raw measurements and units. Distinguish throughput, latency, memory use, cost, and quality metrics. Include variance or distribution where meaningful. Do not compare results produced under materially different workloads or environments without explaining the difference.

Benchmarks must not imply universal performance from a single run. Failed, excluded, and incomplete runs must be disclosed.
