# HIES Sample Product

This deliberately small sample demonstrates how a product repository vendors and validates HIES contracts. It is a fixture inside the HIES repository, not a separately released product.

## Included evidence

- `product-manifest.json`: product identity and runtime contract.
- `compatibility.json`: a synthetic compatibility record.
- `THREAT_MODEL.md`: example trust boundaries and abuse cases.
- `artifacts/`: a harmless sample artifact with a matching SHA-256 manifest.

The example proves schema and metadata tooling works on a representative product layout. It does not prove container hardening, hardware support, production security, or actual product functionality.
